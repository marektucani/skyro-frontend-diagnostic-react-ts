# Fáza 1 – layout a vizuál

Podľa [`design/product-card-sketch.png`](design/product-card-sketch.png) vytvor komponent produktovej karty pre bezdrôtové slúchadlá.

- použi údaje zo `src/data/product.ts`,
- karta musí prijímať produkt cez správne typovaný `props`, aby fungovala aj s iným produktom,
- zobraz obrázok, kategóriu, názov, popis, cenu a dostupnosť,
- rozumne interpretuj layout, spacing, typografiu, farby a proporcie mockupu,
- hodnoty produktu nevpisuj priamo do JSX,
- aplikácia nesmie mať chyby v konzole.

Interaktívne ovládanie zatiaľ nemusí byť funkčné. Po dokončení pokračuj fázou 2.
